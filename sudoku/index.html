How to Play

The goal

Fill the 9×9 grid so that every row, every column and every bold-bordered 3×3 box contains the digits 1–9, each exactly once. The pre-filled bold numbers are fixed and can't be changed.

Playing

  • Click a cell (or move with ←↑→↓ / WASD) to select it.
  • Press 1–9 or tap the digit pad to fill it. Wrong entries turn red at once; the small number on each pad key shows how many of that digit are still to place.
  • 0, ⌫ or the Erase button clears a cell.

Pencil notes

  • Toggle notes mode with N (or the ✎ button). Digits then toggle small pencil marks instead of being placed.
  • Placing a real digit automatically removes that digit's notes from every neighboring cell (row, column, box).

Mistakes, hints & undo

  • Every wrong placement counts as a mistake. With the 3-miss rule on (footer toggle, on by default) the game ends after 3 mistakes — turn it off for open-ended play.
  • H reveals a correct digit, 3 times per game (it fixes a wrong cell first).
  • U undoes anything — placements, notes, erases, hints, even the fatal third mistake.
  • C flashes all currently wrong cells.

Difficulty

Easy starts with 36 given digits, Expert with as few as 24. Fewer givens means more deduction — every puzzle still has exactly one unique solution.

Getting started

Look for a row, column or box with only one empty cell — the missing digit is forced. Then scan for digits that already appear in most peers; the one remaining spot is often forced too. Notes keep track of what's left.
